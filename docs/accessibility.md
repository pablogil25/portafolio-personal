# Accesibilidad

El proyecto debe cumplir como minimo WCAG AA.

## Reglas base

- Usar HTML semantico.
- Mantener una jerarquia correcta de encabezados.
- Asegurar navegacion completa por teclado.
- Definir estados `focus-visible` claros.
- Mantener contraste suficiente entre texto y fondo.
- Usar textos alternativos utiles en imagenes.
- No comunicar informacion solo con color.
- Respetar `prefers-reduced-motion`.
- Asociar formularios con labels reales.
- Evitar trampas de foco en menus o modales.

## Criterio de mantenimiento

Cada nuevo componente o seccion debe revisarse con teclado, lector semantico del navegador y Lighthouse.

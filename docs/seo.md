# SEO

El SEO del portafolio debe ayudar tanto a buscadores como a previsualizaciones en LinkedIn, GitHub, WhatsApp y otras plataformas.

## Reglas base

- Un `h1` claro por pagina.
- Metadatos descriptivos y unicos.
- Open Graph.
- Twitter Cards.
- URL canonica.
- `robots.txt`.
- `sitemap.xml` cuando existan varias paginas.
- Datos estructurados JSON-LD para persona, sitio web y proyectos.
- Imagenes especificas para compartir.
- Buen contenido textual, no solo elementos visuales.

## Futuro

Si el proyecto crece a paginas de proyectos o blog, cada ruta debe tener metadatos propios.

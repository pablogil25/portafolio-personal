# Rendimiento

El portafolio debe sentirse rapido en dispositivos moviles y pantallas grandes.

## Reglas base

- Usar imagenes optimizadas para web.
- Preferir `webp` para imagenes fotograficas y screenshots.
- Definir ancho y alto en imagenes para evitar layout shift.
- Usar carga diferida en imagenes no criticas.
- Limitar pesos y familias tipograficas.
- Usar `font-display: swap`.
- Mantener JavaScript pequeno y modular.
- Evitar animaciones costosas.
- Reducir CSS no usado.
- Evitar dependencias pesadas.

## Objetivo Lighthouse

La meta es mantener altos puntajes en Performance, Accessibility, Best Practices y SEO desde el inicio, no al final.

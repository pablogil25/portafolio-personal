# Deployment

Este proyecto puede publicarse como sitio estatico.

## Opciones recomendadas

- GitHub Pages
- Netlify
- Vercel
- Cloudflare Pages

## Checklist antes de publicar

- Revisar enlaces externos.
- Optimizar imagenes.
- Validar HTML.
- Ejecutar Lighthouse.
- Revisar responsive en mobile, desktop y pantallas grandes.
- Verificar metadata social.
- Confirmar que CV y documentos descargan correctamente.

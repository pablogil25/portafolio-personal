# Guia De Contenido

El contenido editable debe vivir fuera del HTML siempre que sea posible.

## Perfil

Usar `src/content/profile.json` para datos principales como nombre, rol, ubicacion, resumen y enlaces.

## Proyectos

Usar `src/data/projects/projects.json` para la lista completa de proyectos.

Usar `src/data/projects/featured-projects.json` para controlar cuales aparecen destacados.

## Certificados

Usar `src/data/certificates/certificates.json` para metadata de certificados.

Los PDFs deben ir en `public/documents/certificates/`.

Las imagenes deben ir en `public/images/certificates/`.
